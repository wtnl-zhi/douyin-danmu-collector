# 抖音直播弹幕采集与分析桌面软件

## 1. 项目目标

开发一款 macOS 优先的桌面软件。用户输入抖音直播间链接并点击“开始抓取”后，软件通过 Chrome DevTools Protocol 监听该直播页的 WebSocket 消息，实时解析弹幕并展示、持久化保存。用户停止任务后，可导出 CSV 或 SQLite 数据库，并为本次任务生成蓝色关键词云 HTML。

首版聚焦单个直播间、单次采集任务，保证数据采集、实时展示、保存导出和分析闭环可稳定使用。

## 2. 已验证的技术前提

当前链路已经在真实直播间中验证：

```text
直播间链接
  → 隔离 Chrome（CDP 调试端口）
  → Network.webSocketFrameReceived
  → gzip + Protobuf 解码
  → WebcastChatMessage
  → SQLite 持续写入
  → 实时界面 / CSV / 关键词云
```

已成功解析的实时字段包括加密用户 ID、昵称、弹幕内容、消息 ID 与时间戳。采集器将原始二进制帧一并保留，便于抖音协议变化后的排查和重新解析。

## 3. 目标用户流程

1. 用户打开桌面软件。
2. 在“直播间链接”输入框粘贴抖音直播间 URL。
3. 点击“开始抓取”。
4. 软件启动或复用隔离的调试 Chrome，并连接直播间实时消息流。
5. 主界面持续显示最新弹幕；同时数据立即写入本地 SQLite。
6. 用户可搜索、筛选、屏蔽指定内容，并按时间段查看弹幕。
7. 用户点击“停止抓取”。
8. 软件展示保存与分析面板：导出 CSV、导出 SQLite、生成/导出关键词云 HTML。
9. 用户可打开历史任务，重新查看、筛选、导出或生成词云。

## 4. 功能范围

### 4.1 直播间任务管理

- 输入和校验直播间链接。
- 创建单个采集任务；首版同一时间仅允许一个活跃任务。
- 展示任务状态：未开始、连接中、抓取中、重连中、已停止、异常。
- 显示直播间链接、任务开始/结束时间、连接时长、弹幕总数和当前抓取速率。
- 采集过程中禁用重复开始；停止后允许新建任务。
- 自动重连：网络波动、直播刷新或 CDP 连接重建后，指数退避重连。
- 直播结束或页面不可用时展示可理解的原因，保留已采集数据。

### 4.2 实时弹幕流

- 最新弹幕置顶或置底显示（首版默认最新在上，可在设置中切换）。
- 每行展示：弹幕时间、用户 ID、用户名、弹幕内容。
- 默认用户 ID 脱敏显示；设置中可切换为完整显示。
- 支持关键词搜索和时间范围筛选。
- 支持屏蔽词：命中时不在实时列表显示，但仍可选择是否保留至数据库。
- 支持暂停界面滚动；暂停仅影响显示，不影响后台写入。
- 支持复制单条弹幕和复制当前筛选结果。

### 4.3 数据持久化

选择 SQLite 作为首版默认数据库：无需安装独立服务、单文件便于备份和交付、适合本机桌面采集。

**重要原则：** 数据从“开始抓取”时即持续写入 SQLite，不等待“停止抓取”后一次性保存，以避免意外退出造成数据丢失。

建议数据模型：

#### `capture_sessions`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT / UUID | 采集任务唯一 ID |
| `room_url` | TEXT | 用户输入的直播间链接 |
| `room_id` | TEXT | 可取得时保存的直播间 ID |
| `started_at` | INTEGER | 任务开始毫秒时间戳 |
| `stopped_at` | INTEGER | 任务结束毫秒时间戳 |
| `status` | TEXT | stopped / failed 等状态 |
| `message_count` | INTEGER | 已采集弹幕数量 |

#### `danmu_messages`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER | 本地自增主键 |
| `session_id` | TEXT | 所属采集任务 |
| `message_id` | TEXT | 平台消息唯一 ID，用于去重 |
| `user_id` | TEXT | 平台返回的加密用户 ID |
| `username` | TEXT | 用户昵称 |
| `sent_at_ms` | INTEGER | 平台弹幕时间，毫秒时间戳 |
| `received_at_ms` | INTEGER | 本机接收时间，毫秒时间戳 |
| `content` | TEXT | 弹幕内容 |
| `raw_frame_id` | INTEGER | 对应原始 WebSocket 帧，可选 |

唯一约束：`(session_id, message_id)`，避免重连或刷新时重复入库。

#### `raw_ws_frames`

保留原始 WebSocket 二进制帧、接收时间、哈希和连接信息。此表默认启用，作为协议兼容性与数据追溯保障；可在设置中提供“节省空间模式”关闭。

### 4.4 停止、保存与导出

用户点击“停止抓取”后显示任务结果面板：

- **导出 CSV**
  - 仅导出当前任务或导出全部历史任务。
  - UTF-8 with BOM 编码，确保 Windows Excel 直接打开中文不乱码。
  - 字段：弹幕时间、用户名、用户 ID、弹幕内容、消息 ID。
- **导出 SQLite**
  - 导出当前数据库副本，或仅包含当前任务数据的精简 SQLite 文件。
- **导出 Excel（.xlsx）**
  - 第一版加入。字段和 CSV 一致，适合业务人员直接使用。
- **打开数据目录**
  - 快速打开数据库、导出文件和日志所在位置。

### 4.5 关键词云与词频分析

- 基于当前任务或用户选定时间段的弹幕内容生成。
- 支持中文分词、最小词长、最小词频和自定义停用词。
- 默认过滤常见无意义词、纯数字、URL 和低频噪声。
- 提供可编辑屏蔽词和同义词合并规则。
- 所有词均使用蓝色呈现；频率越高字体越大。
- 默认字号范围 14–60px，按词频相对值映射。
- 软件内 HTML 预览，并支持导出独立 `.html` 文件。
- 同时显示词频 Top 50 表，包含词语、频次和占比，便于审核词云结果。
- 支持按最近 10 分钟、30 分钟、1 小时、全程或自定义时间段重新生成。

### 4.6 设置与可维护性

- 默认时区：Asia/Shanghai；界面同时支持显示绝对时间和相对时间。
- 设置调试 Chrome 配置、数据库目录、原始帧保存开关、滚动方向、ID 脱敏规则。
- 日志查看与一键复制诊断信息。
- 明确区分“用户未登录”“直播间不可访问”“网络断开”“协议解析失败”等错误状态。
- 不向第三方上传弹幕内容；词云在本地生成。

## 6. 技术方案

| 层级 | 选型 | 职责 |
|---|---|---|
| 桌面应用 | Electron + React + TypeScript | 界面、任务管理、实时数据展示、导出和设置 |
| 采集服务 | Node.js + Chrome DevTools Protocol | 启动隔离 Chrome、监听 WebSocket、断线重连 |
| 解码器 | gzip + Protobuf | 解析 `WebcastChatMessage` 中的用户与弹幕字段 |
| 本地数据库 | SQLite（WAL 模式） | 任务、弹幕、原始帧、导出来源 |
| 词云 | 本地中文分词 + HTML/CSS/SVG | 生成全蓝色可导出的词云 |
| 导出 | CSV、XLSX、SQLite | 面向运营、分析与备份 |

应用使用独立 Chrome Profile，避免读取或改变用户日常 Chrome Profile。若抖音要求登录，用户在隔离窗口完成登录；账号数据仅保留在该隔离 Profile 本地。

## 7. 分阶段开发计划

### 阶段 1：采集内核产品化

- 将已验证的 CDP/WebSocket/Protobuf 链路封装为独立采集模块。
- 完善直播间 URL 校验、任务状态机、重连、去重和结构化日志。
- 提取并保存 `user_id`、昵称、内容、消息 ID、平台时间。
- 完成 SQLite schema、迁移与会话隔离。
- 验收：连续抓取 30 分钟，无重复消息、无崩溃；断网恢复后自动继续采集。

### 阶段 2：桌面应用基础界面

- 创建 Electron + React + TypeScript 工程。
- 完成直播间链接输入、开始/停止按钮和状态展示。
- 将采集模块以本地 worker/子进程运行，避免阻塞 UI。
- 验收：可从界面创建、运行和停止一项真实采集任务。

### 阶段 3：实时弹幕与查询

- 实现虚拟滚动实时列表。
- 实现关键词、时间范围、屏蔽词、暂停滚动和 ID 脱敏。
- 显示任务统计信息。
- 验收：10,000 条以上历史弹幕下界面保持可用；筛选结果与数据库一致。

### 阶段 4：保存与导出

- 实现当前任务/全部历史任务的 CSV、XLSX、SQLite 导出。
- 实现导出进度、成功提示和打开所在目录。
- 验收：导出的 CSV、XLSX、SQLite 三者记录数、字段和值一致；Excel 中文不乱码。

### 阶段 5：关键词云

- 实现分词、停用词、时间范围和词频统计。
- 实现全蓝色 HTML 关键词云与词频 Top 50 表。
- 实现 HTML 导出与预览。
- 验收：高频词字号显著更大；词云频次与表格、原始弹幕数据一致。

### 阶段 6：稳定性、打包与交付

- 完善错误处理、日志、数据目录管理和异常恢复。
- macOS `.dmg` / `.app` 打包；准备 Windows 扩展预留。
- 完成测试与使用说明。
- 验收：全新 macOS 用户可安装、登录隔离 Chrome、开始抓取、导出和生成词云。

## 8. 验收标准

### 采集正确性

- 输入有效直播间 URL 后能在 30 秒内进入“抓取中”或给出明确失败原因。
- 实时列表与 SQLite 中 `danmu_messages` 的记录一致。
- 每条弹幕包含时间、用户名、用户 ID、内容和消息 ID。
- 同一任务内不重复保存同一 `message_id`。
- 断网或页面刷新后自动重连；已保存数据不丢失。

### 数据导出

- CSV、XLSX 和 SQLite 均可导出。
- CSV 在 Microsoft Excel 中中文显示正常。
- 导出记录数与所选任务、筛选条件一致。

### 词云

- 生成 HTML 文件且可以离线打开。
- 所有词为蓝色。
- 词频越高字号越大。
- 支持时间范围、停用词和最低词频设置。
- Top 50 词频表可以追溯到对应的弹幕数据。

### 隐私与可靠性

- 用户日常 Chrome Profile 不被读取或修改。
- 弹幕、数据库和词云默认仅保存在本机。
- 错误日志不记录用户凭据、Cookie 或账号密码。
